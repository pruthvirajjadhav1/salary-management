# Demo video script (about 4 minutes)

A walkthrough that follows the HR manager's questions rather than the menu.

1. **Pay overview (0:00–0:40).** "10,000 people, 8 countries. Payroll is about $866M, and every cross-country figure says '≈ USD' because it is converted at a dated reference rate." Point at the country bands, which all sit on one USD scale: India's band sits far left, the US far right. Mention payroll by department.
2. **Answer a question (0:40–1:20).** "What is the average Software Engineer salary in India?" Click India. Everything is now in rupees, with lakh/crore grouping. Read the Software Engineer row: average, median, range. Sort by median. Filter to Engineering.
3. **Drill to people (1:20–1:50).** Click the Software Engineer row. The directory opens filtered to India and Software Engineer. The URL holds the filters, so reloading or sharing the link keeps them. Sort by salary. Point out that sorting compares USD equivalents.
4. **One person (1:50–2:40).** Open a profile. Show the current salary, the peer band with the amber marker and the compa-ratio chip, and the salary history with percentage changes.
5. **Record a raise (2:40–3:20).** Click Edit and change the salary. The pay-change panel appears with old → new and the % change. Pick "Promotion" and save. A toast confirms, the history gains a row and the compa-ratio updates.
6. **Guard rails (3:20–3:45).** Add an employee with an existing email. The error appears on the email field (409 from the API). Export the CSV and open it in Excel.
7. **Close (3:45–4:00).** Show the commit history and the `docs/` folder. Name what was deliberately left out: auth, import, pay equity.
